# hey! Bus

한국 중고버스와 현대 카운티를 국내 판매와 수출로 소개하는 사이트입니다. 재고는 하나이며, 국내에서 판매가 끝나면 수출 화면에도 같은 상태가 반영됩니다.

외부 키가 없으면 데모 모드로 실행됩니다. 데모 매물과 접수는 실제 재고·실제 상담이 아닙니다.

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 을 엽니다. `/` 는 `/ko` 로 이동합니다.

데모 계정:

- 관리자: `admin@demo.kbus` / `demo-admin`
- 승인 에이전트: `agent@demo.kbus` / `demo-agent`
- 추천 코드: `DEMOAGT1`

환경변수로 데모 계정을 바꿀 수 있습니다. 운영 모드에서는 데모 계정이 동작하지 않습니다.

확인:

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## 환경변수

`.env.example` 을 `.env.local` 로 복사합니다. 예제 파일에는 자리표시자만 있습니다.

| 변수 | 설명 |
| --- | --- |
| `DATA_SOURCE` | 비우면 키가 있을 때 Supabase, 없으면 데모. `demo` 또는 `supabase` |
| `NEXT_PUBLIC_SITE_URL` | 공유 링크와 sitemap에 쓰는 공개 주소 |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 프로젝트 URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | 브라우저에 노출 가능한 anon 키 |
| `SUPABASE_SERVICE_ROLE_KEY` | 서버 전용. `NEXT_PUBLIC_` 를 붙이지 않습니다 |
| `DEMO_ADMIN_EMAIL` / `DEMO_ADMIN_PASSWORD` | 데모 관리자. 비우면 기본 데모 계정 |
| `DEMO_AGENT_EMAIL` / `DEMO_AGENT_PASSWORD` | 데모 에이전트 |
| `DEMO_SESSION_SECRET` | 데모 세션 서명. 운영 전에 바꿉니다 |
| `DEMO_DATA_DIR` | 데모 저장 폴더. 기본 `.data` |

키가 일부만 있거나 `DATA_SOURCE=supabase` 인데 키가 없으면 데모 화면으로 대체하지 않고 설정 오류를 보여 줍니다.

## 데이터베이스

`supabase/migrations/0001_init.sql` 다음에 `0002_members_and_review.sql` 을 적용합니다. 데모 자료는 운영 DB에 넣지 않습니다.

공개 읽기는 판매 중·예약·판매 완료 매물, 그 사진, 사이트 설정만 허용합니다. 검토 중 매물과 회원 정보는 공개 조회에서 빠집니다. 내부 원가, 문의, 견적, 요청, 역할, `member_profiles` 는 `anon` 과 `authenticated` 에서 권한이 제거되어 있고, 서버의 service role 로만 다룹니다. 사용자는 자신의 관리자 권한을 만들 수 없습니다. 차량의 `owner_id`, 판매자 이름·이메일·상호, 등록 출처 열도 공개 역할에서 select 가 제거되어 있습니다.

최초 관리자:

1. Supabase Authentication에서 관리자 사용자를 만듭니다.
2. 그 사용자 UUID로 역할을 넣습니다.

```sql
insert into public.user_roles (user_id, role)
values ('00000000-0000-0000-0000-000000000000', 'admin');
```

에이전트는 사이트에서 가입 신청을 한 뒤, 관리자가 승인하고 Supabase 사용자 UUID를 연결해야 로그인됩니다. 승인만으로 메일을 보내지 않습니다.

Storage 버킷 `vehicle-photos`, `private-files` 는 비공개입니다. 사진은 앱의 `/api/media/photo` 를 통해서만 공개되고, 매입 첨부파일은 로그인한 관리자만 받습니다.

## 영업 전에 넣을 정보

관리자 → 사이트 설정:

- 회사명, 전화, 이메일, 주소, 영업시간
- 카카오톡 `https://` 링크, WhatsApp 국가번호 숫자(`+` 없이)
- 회사 소개 한국어·영어
- 개인정보 안내 한국어·영어

연락처를 비우면 공개 화면은 가짜 번호 대신 문의 폼을 보여 줍니다. 개인정보 수집은 한국어·영어 안내를 저장한 뒤에만 켤 수 있습니다. 끄면 운영 모드에서 문의·요청·가입 신청을 저장하지 않습니다.

매물은 관리자 → 매물 관리에서 등록합니다. 국내 가격과 수출 가격·통화·조건을 따로 입력합니다. 가격이 없으면 가격 문의로 표시합니다. 환율로 수출가를 만들지 않습니다. 사진이 없으면 사진 자리만 표시하고, 모르는 사양은 미확인으로 둡니다.

회원가입은 판매 사업자와 일반 고객을 나눕니다. 판매 사업자만 내 차 팔기에서 매물을 등록하고, 정면·정측면·후면 사진이 필수입니다. 등록 직후 상태는 검토 중이며 관리자가 판매 중으로 바꾸기 전에는 공개 목록에 나오지 않습니다. 일반 고객은 매물을 올리지 않고 매매 상담만 남깁니다. 운영 모드 가입은 개인정보 수집이 켜진 뒤에만 저장됩니다. 서버가 `email_confirm` 으로 사용자를 만들어 메일 공급자가 없어도 로그인할 수 있습니다. 그 키는 서버에만 둡니다.

데모 매물에는 느낌을 보기 위한 샘플 사진이 들어 있습니다. 데모 배너와 사진 안내처럼 실제 재고 사진이 아닙니다. LOGO 자리와 영상 자리는 실물 파일을 넣기 전의 표시입니다. 로고는 가로 워드마크와 정사각 마크(SVG 또는 투명 PNG), 히어로·야드는 실차나 야드 가로 약 2400px, 매물 사진은 정면·정측면·후면과 가능한 실내·계기판·엔진·타이어·결함, 영상은 자동 재생하지 않는 짧은 실차 링크를 준비하면 됩니다. 운영 공개 전에는 데모 샘플을 실제 매물 사진으로 바꾸세요.

## 범위 밖

경매, 온라인 결제, 실시간 채팅, 모바일 앱, 운임 자동 계산, 국가별 수입 규정 판정, 자동 수수료 정산, 마케팅 메시지 발송은 포함하지 않습니다. 판매 사업자 등록은 검토 전 공개 입점이 아닙니다.
